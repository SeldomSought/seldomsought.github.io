02 / Operating Principle

“Visibility is not luck. It's the result of building the right systems in the right places at the right time.”

That line is the practice's own operating note, and the pattern holds outside marketing, too. Every independent build in the record below runs client-side by default — no server required, no account, no data leaving the device unless someone chooses otherwise. That isn't a privacy feature added afterward; it's the default assumption going in.

Twelve fields of practice, one working assumption underneath all of them: build the system so it doesn't depend on someone else's.

03 / Selected Evidence

Independent record

No client names disclosed here. What follows is public, independent, and shipped — the account with the fewest strings attached.

File 01 Chrome Extension Status — Beta

Focus Shield

Enforces a 30-minute daily budget on passive feed browsing. Feeds are suppressed at the CSS level before JavaScript executes; bookmarks and creation tools stay accessible without limit. An optional commitment lock, keyed to a passphrase held by someone else, makes the limit difficult to defeat by design.

Stack — JavaScript · Chrome MV3 · Service Worker · MutationObserver API · IndexedDB · Webhooks

File 02 Web App Status — Beta

Psychometric Battery

A 142-item assessment integrating four validated measurement frameworks — HEXACO personality, forced-choice ranking, Schwartz values, attachment style — into a single session. Scoring runs entirely in the browser; nothing is transmitted.

Stack — JavaScript · HTML/CSS · client-side only · zero dependencies

File 03 Chrome Extension Status — Beta

Bookmark Mirror

Generates a psychological profile from Twitter/X bookmarks — Big Five inference, Schwartz values, LIWC-inspired linguistic analysis, topic velocity — entirely offline. No API key, no server, no data transmitted.

Stack — JavaScript · Chrome MV3 · IndexedDB · Content Scripts · Service Worker

File 04 Instagram Status — Live

Curated Feed

Every post on @seldomsought resequenced by hue instead of time — manually, post by post, no algorithm. The chronological grid becomes a continuous color gradient.

Stack — Manual curation · color theory

File 05 Web App Status — Prototype

The Self Cartography Project

An evidence-informed self-assessment that triangulates values, personality, and career fit across ten measurement formats — not just Likert ratings — with a background validity engine that flags straightlining, contradiction, and self-report-vs-behavior gaps. Every score ships with a confidence level, never an invented percentile.

Stack — React · TypeScript · Vite · client-side only
